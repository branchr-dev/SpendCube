### Learnings
- `is_on_contract` column does NOT exist in the SQLite transactions table (not in schema in database.py).
  The contract_coverage_gap rule defaults to 0% coverage when column absent — correct behaviour.
- 10-row sample data only triggers TAIL_SPEND_RATIONALISATION (tail_spend_pct=13.9% > 5% threshold).
  Maverick spend pct is ~0% because intercompany/tax rows are excluded by _addressable() filter.
  CONTRACT_COVERAGE_GAP doesn't fire because no L1 category reaches > $20,000 after exclusions.
  Remaining rules need 1000-row dataset to fire (US-008 validation).
- The `by_supplier` cube view does NOT include canonical_supplier_id — grouped by name only.
  Payment term extension rule must therefore work from transactions DataFrame directly.
