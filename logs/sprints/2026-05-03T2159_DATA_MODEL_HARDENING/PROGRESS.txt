## US-004 COMPLETE — 2026-05-03
Created src/ingestion/promoter.py with IncrementalPromoter class.

Key design decisions:
- _resolve_suppliers() normalises all raw_supplier_names, computes SHA256[:12] canonical_supplier_id for each, queries supplier_master in one batch, and only runs SupplierHarmoniser for names whose expected canonical_supplier_id is NOT already in the table.
- Known names get confidence=0.95 (exact normalised name match); unknown names use the match_log confidence from harmoniser.
- categorise() is called with a deep-copied config where llm.dry_run=True — guarantees no LLM API calls regardless of the original config.
- _build_records() maps only columns in _TX_COLUMNS to avoid inserting transactions_raw-specific columns (id, batch_id, source_row_hash, pipeline_status) into the transactions table. Sets source_raw_id per acceptance criteria.
- Promoted/review split is purely by confidence >= 0.60 (MANUAL/DETERMINISTIC methods always score >= 0.60, so no special-case needed).

## US-005 COMPLETE — 2026-05-03
Added PgvectorEmbeddingStore class to src/suppliers/embeddings.py and wired it into EmbeddingMatcher.encode().

Key design decisions:
- PgvectorEmbeddingStore.is_available() caches result in self._available after first probe — avoids repeated DB round-trips per encode() call.
- get() uses parameterised IN clause (n0, n1, ...) to avoid SQL injection; fetches from supplier_embeddings filtered by both engagement_id and normalised_name.
- store() inserts in chunks of 500; uses ON CONFLICT (engagement_id, normalised_name) DO NOTHING — safe to re-run.
- encode() pgvector path: load pg hits → encode remaining → store new to pgvector → save pickle cache. The pickle is still updated so it stays warm for SQLite/offline sessions.
- When pgvector_store=None (default), encode() behaviour is byte-for-byte identical to the original implementation.
- All 51 supplier tests pass unchanged ✓; import OK ✓
